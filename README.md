# Medical-Data-Hub 

## Clinic API

Platform administrators can register a clinic and its first administrator with [`POST /clinics`](docs/design.md#clinic-registration-endpoint).

Clinic administrators can register users in their clinic with [`POST /users`](docs/design.md#clinic-user-registration-endpoint).

## Audit API

Clinic administrators can query audit metadata with [`GET /audit-records`](docs/design.md#audit-record-query).
